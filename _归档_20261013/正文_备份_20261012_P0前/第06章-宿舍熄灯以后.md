# 第6章 宿舍熄灯以后

十六岁的人谈将来，是畅想；三十九岁的人谈将来，是剧透。

307宿舍，八个人，四张铁架床，睡下五湖四海。

靠门下铺，周凯，铁路边平房区的，嗓门和胆子都是宿舍之最。
李志明床头用铁丝弯了个架子，专门挂他那瓶宝贝咸菜——玻璃罐头瓶装的，他妈亲手腌的，一撮咸菜丝能就两个馍。

周凯对面，靠窗下铺，李志明。

李志明对面，白胖小子，刘卫东，城里的，家里开粮油店。
这厮每周日返校，编织袋里除了被子还有吃的：咸肉罐头、豆瓣酱、香油瓶，窗台摆得跟小卖部一样。
开学第二周，外号就有了——馍总。因为李志明能就着一切东西吃馍，并且热情推销：“来，夹一口，得劲！”

上铺还有个张小峰，戴眼镜，瘦得像根笔芯，睡着了手里还攥着单词本。
人送外号“清华”，因为李志明开学第一天自我介绍，说的是“我想考清华”。全班笑了，李志明自己没笑。

另外几个，高个的赵磊，话少，球瘾大；还有俩床位换得勤，印象不深。

熄灯以后，是307的黄金时段。

李志明上辈子远离这种生活太久了，头几晚上听着听着就笑出声。
十六岁男生的卧谈会，天上一半，地下一半，一半在南方，一半在同桌。

“卫东，你表哥那号，裁决卖了没？”

“不卖！出两百都不卖！”刘卫东的声音在黑暗里嗡嗡的，嘴里似乎还嚼着什么，“我表哥说了，攒到过年，换把更好的！”

李志明在黑暗里听着，心想这大概是他两辈子听过的最早期也最真诚的长期主义——一把虚拟的裁决之杖，

撑起了一个厂区少年的全部战略定力。

“两百块！”周凯砸了砸嘴，“我妈起早贪黑炸俩月油条，也就挣这个数。”

“那你说姚明一年挣多少？”

“美元！论美元你懂不懂！”

“多少也是人家的。哎，你们说，一班那个扎辫子的女生，长得好看不？”

“中啥中，没看见咱班陈冉——”

话头忽然刹住了，黑暗里一阵坏笑。

李志明躺在被窝里，睁着眼。

陈冉。

两个字进了耳朵，像一粒火星子掉进干柴堆。他没吭声，只在黑暗里，把这两个字在心里描了一遍。

前桌还没正式说过话。不急。

话题转到了鬼故事上。
赵磊讲的，说是学校后墙外那个坑塘，早年间淹死过人，一到夏天就有人听见塘里有动静——“扑通，一声；再一听，又是一声。
“跟有人往下跳一样。”

一宿舍人安静了。

安静了三分钟，有人小声说：“我想尿尿。”

“我也想。”

“谁去？”

“集体行动。”

黑暗里窸窸窣窣穿了半天衣裳，八个人挤挤挨挨去厕所，去了六个人——张小峰说自己不带怕的，留守；李志明说自己腰不行，也留守。

这个理由无懈可击：腰是真闪过的，膏药不能白贴。

等他们回来，宿舍里重新躺定，周凯忽然发起了新话题：

“哎，都说说，长大想干啥？我先来！”李志明清了清嗓子，庄重得像宣誓，“我要去南方！我表哥在那边电子厂，一个月一千八！
“包吃住！”

“一千八？！”刘卫东坐起来了，“这么多钱咋花？”

“存着！存够本，我自己当老板！”

“我简单。”刘卫东说，“接我爸的粮油店。然后开分店，东关一个，西关一个。”

轮到张小峰，他在上铺翻了个身，声音不大：“考清华。”

这回没人笑。

周凯带头说：“峰哥，行。你先考上，叫我们沾沾光。”

再往下问了两个，一个说“不知道”，一个说“跟我姑学裁缝”。最后问到李志明。

李志明想了想，说：“先把这个月过好。”

“切——”黑暗里一片嘘声。

“再把这个学期过好。”

“你这人，”周凯在上头翻了个身，床架吱呀乱响，“一眼望到头，没劲！”

一眼望到头。

李志明在黑暗里咧了咧嘴，没说话。

我这一眼，望的是二十三年。你在2012年冬天跟我要了二百块钱，然后就没有然后了。你管这叫没劲？

这话李志明不能说。说了，今晚就都别睡了。

后半夜，宿舍睡熟了，鼾声此起彼伏。李志明也迷迷糊糊快睡着的时候，床边有人轻轻碰了碰李志明胳膊。

周凯蹲在床边，声音压得很低：“志明，睡了没？”

“没。咋了？”

“……跟你说个事。”周凯的声音跟白天那个大嗓门判若两人，“我爸，以前在货场扛包，前年冬天闪了腰，坏了。
“重活干不了，现在给人看仓库，一个月三百。我妈凌晨三点起来和面炸油条，一早上站六七个钟头。”

李志明没吭声，等着他说下去。

“我家的钱，都给我爸抓药了。”周凯说，“我这周带的馍钱，是我妈一个鸡蛋一个鸡蛋攒出来的。其实……我不想念了。
“念也念不出头，不如早点出去打工。我妈非叫念，拿笤帚追了我二里地。”

黑暗里，这孩子自嘲地笑了一声：“你说可笑不可笑，我坐教室里啃咸菜，一天三顿，顿顿觉得对不起我妈。”

李志明在黑暗里看了他很久。

前世这些话，凯子从来没跟李志明说过。他们是高二才熟起来的，这些事，李志明都是后来、再后来，零零碎碎从别人嘴里拼出来的。
原来李志明现在嘴里的每一句“挣钱”“南方”“当老板”，底下都压着这些。

“凯子。”

“嗯？”

“好好念。往后想挣钱，我带你。”

周凯愣了几秒，忽然咧开嘴笑了，那口白牙在黑暗里都发亮：“中！这话可搁这儿了啊，谁变卦谁是狗！”

“谁变卦谁是狗。”

凯子心满意足地回了床上，不到三分钟，鼾声就起来了，打得又香又沉。

李志明却再也睡不着了。

李志明躺在黑暗里，听着满屋子十六岁的呼吸声，一个一个地想过去。
这间屋里的人，往后三十年是什么样，李志明大体都知道。

谁发了小财。

谁离了两次婚。

谁的孩子考上了大学。

谁的后事是同学凑钱办的。

斜对角那个戴眼镜的，是这屋里唯一一个念到大学的。

上铺那个刚跟他击过掌、发过誓的，六年后会站在省城火车站，跟他借二百块钱。

然后就没有然后了。

他们现在都躺在黑暗里，呼吸又匀又沉，谁也不知道自己往后是什么样。

只有他知道。

有那么一瞬间，他很想摇醒上铺那个，跟他说：你六年后别去南方。

可说什么呢？

“嘿，我做了个梦，梦见你六年后站火车站跟我借二百块钱。”

周凯大概会嘿嘿笑两声，翻个身接着睡。

李志明知道自己知道这些，是一种残忍。

李志明在心里，轻轻问了一句：

“如果我把所有的事都改了……他们，会怎么样？”

黑暗里，那个声音答得很快，快得像等这个问题等了很久：

【我不知道。但可以确定的是——他们不会是你记忆里的那些人了。】

李志明盯着上铺的床板，把这句话翻来覆去咂摸了半宿。

他一直以为自己要做的事，叫“改命”。

这一刻李志明才咂摸过味儿来——

李志明改的不是命。

是人。
