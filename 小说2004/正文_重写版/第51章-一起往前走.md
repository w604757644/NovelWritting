# 第51章 一起往前走

出发前一晚，王秀兰把李志明的行李重新打开。

他在旁边看了半天，忍不住问：“妈，这个包是不是还可以再长大一点？”

“装得下。”

“我担心到了车站，别人先叫它上车，再问我跟不跟着走。”

母亲笑着拍他一下，手里那件薄外套却没有放回去，说京城开学以后早晚会凉，带着没坏处。

李志明接过来，自己叠好。

父亲坐在桌边，将车票和证件又核了一遍，提醒到站以后别急着往外走，先确认东西都拿齐。他点头，说路上跟陈冉、凯子都约好了，不会一个人乱跑。

几个学校报到时间不完全一样，他们商量过行程，选了能一起出发的这一趟。谁到校以后先安顿好，再去帮另一个，不指望一张车票把后面的事全办妥。

母亲听着，又问钱放在哪儿。他指给她看，分开放好，连她准备再叮嘱的几句也一并答了。

王秀兰这才坐下来。

“到了记得打电话。”

“到了就打。”

“吃饭别总凑合。”

“知道。”

她还想说，李志明便把椅子拉近一点，认真听着，没有再嫌她重复。

······

桌上收得干干净净，只留几本不带走的书。

李志明把工具袋拿出来，检查过，放进行李里。袋子是父亲早先给的，边上磨了一点，里面的东西仍能用。

王秀兰问上大学还修电脑啊。

“不一定修，带着顺手。哪天桌子松了，也能自己紧一紧。”

父亲抬头看了眼，没说什么，过了一会儿，从抽屉里找出一小卷胶带，放到旁边。

“这个也带上。”

李志明笑着收了。

笔记本里那张合照，他没有拿出来换位置。陈冉在照片里偏头看他，暑假的树影落在两人身后。现在书一合，相纸就跟着去了新的地方。

睡前，他跟父亲又说了一回家里的事，提醒后续检查该去就去，别因为他不在家，什么都攒着不讲。

李建国点头，让他把自己的生活也照顾好。

“你妈有我在。”

李志明看着父亲，慢慢应了一声。

这句话，他这一回听进去了。

······

进城坐车那天，几家人在车站碰头。

陈冉穿着浅色上衣，头发束在脑后，手里拎着一个不大的包。看见李志明，她先朝他笑，再走过去跟王秀兰打招呼。

母亲立即问她早上吃了没有，说自己带了点东西，路上饿了两个人分着吃。

李志明在旁边提醒还有凯子。

王秀兰回头，看见周凯正拖着箱子过来，连忙说也有他的。凯子笑着接话，说自己不挑，好养活，只要别把人忘在车站就行。

陈父听着笑，帮他们看了一遍票，再交代女儿到学校先安顿，缺什么再说。陈冉应下来，问父母回去路上是不是还要办事，让他们也别太赶。

两家长辈站在一处，很自然地聊起路程和报到。李志明把大些的行李推到一边，让出通道，顺手接过陈冉手里的水。

陈母看见了，没有说什么，只叮嘱路上互相照顾。

······

凯子母亲提着一个布袋，里面装了吃的。

她要往儿子手里塞，凯子先说太多，话到嘴边，又改口说自己能拿，让她把袋子系紧一点。#先说出口才"话到嘴边"

周父站在旁边，腰挺得比平时直，跟儿子说学校里不懂的多问，别怕别人笑。凯子点头，手却一直扣在箱子的拉杆上。

轮到检票，他突然回身抱了抱母亲。

动作有点笨，布袋夹在两人中间，母亲还得腾手扶一下。他抱完，伸手又跟父亲拍了拍肩，说到了先给家里报平安。

周父笑着骂他没大没小，眼睛却跟着儿子往前走。

李志明看在眼里，心里很踏实。

凯子站在这里，手里有车票，包里有录取通知书。往后，他要去认识自己的老师、同学，也要继续喜欢那个已经去省城念书的女孩。

这回，他跟着走进站的人群，再不会提前把书包扔下。

······

李志明也抱了抱母亲。

王秀兰原先还在说话，被他一抱，声音忽然停住，过了一会儿，才伸手在他背上拍了两下。

“这么大个人了，别让人看笑话。”

“那你别哭，咱们谁也不笑谁。”

“我哪儿哭了。”

母亲推开他，抬手理了下额前的头发。李志明没揭穿，转身看向父亲。

李建国伸手拍了拍他胳膊，说去吧，车别赶不上。

李志明却没立即走，伸手也抱了抱父亲。

李建国身体僵了一下，随即抬起手，拍在他背上。父子俩谁都没再说什么，松开以后，父亲低头看他行李的拉链，问都关好了没有。

“关好了，刚才你检查过。”

“哦，那就行。”

王秀兰站在旁边，想笑，又抬手摸了摸眼角。李志明没拆穿，只将她手里一直替自己拿着的水接过来。

“到站先给家里打，安顿好了再打一回，你们不用一直守着电话。”

“知道。”母亲答得很快，又问，“宿舍要是没电话呢？”

“学校肯定有地方能打。找着就给你们说，你别急。”

她点点头，手已经空了，还低头看了一眼，像是在找还有没有什么该递给儿子的。李建国伸手扶了扶她胳膊，让她往旁边站，别挡着后面的人。

李志明这才提起行李。父亲还想替他送一段，他笑着握住拉杆，说这点自己来就行。

那只提了许多年东西的手，终于慢慢松开了。

他应了一声，拉起行李。走到前面，又回头看了一眼，两个人仍站在原来的地方，母亲举着手，父亲在旁边陪着。#"应了一声"无对象

他把手举高，认真挥了挥。

······

车开以后，凯子先找地方放吃的。

那一袋东西，比他刚才以为的还多。李志明打开自己的袋子，又多出几样，陈冉看着他们一包包往外拿，笑着说这下可以一直吃到京城。

“主打一个有备无患。”李志明说。

凯子往桌上一摆，气势很足：“没到学校，我先体验一下当老板。”

“卖什么？”

“卖不了。我妈给我装的，舍不得。”

陈冉笑起来，拆开一小包，先递给他，再递给李志明。

窗外的房子慢慢往后退，熟悉的街道不见了，田地和树从眼前连成一片。凯子吃了一阵，终于安静下来，靠着椅背看风景。

陈冉坐在李志明身边，手放在腿上，被他悄悄握住。她抬眼看他，没有抽走，反而把手指拢紧了点。

“真出来了。”她说。

“嗯。”

他望着窗外，又想起出发前给糖纸留的那条消息。

日期，车次，还有一句，到了安顿好就找她。

糖纸回得很快，说自己会等，让他路上别只顾看风景，记得看好行李。末尾又补一句，到时候要当面看看，李老板是不是还这么会说话。

李志明想到这里，笑了一下。

陈冉问他笑什么，他转过脸，说以前总想着出了县城会是什么样。现在真坐在车上，反倒觉得往后什么都可以慢慢看。# 糖纸线未收

她点头，将头轻轻靠在他肩上。

凯子从对面睁开眼，看了看，自己往旁边挪了一点，嘀咕早知道该多买一个靠枕。

李志明笑着拿起外套，卷好递给他。

“先凑合，到了给你安排。”

凯子接过去，嘴上说还算有良心，闭眼没多久，就真的睡着了。

车窗上的光慢慢移过去。李志明握着陈冉的手，听见车轮一声声往前滚。

高中已经在身后。

京城还在前面等着他们。
