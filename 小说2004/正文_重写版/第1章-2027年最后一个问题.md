# 第1章 2027年最后一个问题

知了在城里叫了一整个夏天。最后一声，停在八月二十六号深夜。

2027年8月26日，深夜十一点半，李志明还在公司顶楼。

再过两个钟头，他会死在这座城的一场夜雨里。

他不知道。

明天下午三点，未晚科技的年度发布会。全球三千家媒体蹲在线上，门票刚放出来就抢空，所有人等的都是同一样东西：

“知了”。

他带队做了七年的超级AI Agent。最狂的一句评语是：

“距离真正的个人智能体，人类只差一个李志明的距离。”

此刻，这位“只差一个”本人，正在跟PPT上的一句话较劲。

“知了，”他往椅背上一靠，冲着空办公室说，“‘知了将重塑人与信息的关系’，这句话，土不土？”

【土。】

“……你就不能哄哄我？明天上台的人是我。”

【可以。“知了将重塑人与信息的关系”，是你近三年写的版本里，最不土的一版。】

“谢谢，安慰得很有产品味儿。”李志明把PPT翻到下一页，“三年，十七版，最后挑了句最像废话的。听君一席话，如听一席话。”

他干了七年，写过最顺手的两个字是“赋能”。后来他一看见这俩字就想吐。

李志明笑了一声，把凉透的咖啡一口闷了。

顶楼的灯全开着，三千人的公司，这个点只剩他一个。手机搁在桌角，屏幕忽然亮了一下，置顶的那个对话框，“妈”。

一个他拨了十七年也打不通的号码。手机换了四部，数据迁移，置顶没动过。

李志明看了一眼，没点开。

他伸手，把手机翻了个面，屏幕朝下扣在桌上。

兄弟分组里，凯子的头像，十五年没亮过。

按估值算，李志明排得进这座城市的前五十。按“半夜能打电话的活人”算，一个巴掌数得过来。

三千人的公司，他是老板。也是这里最称职的一个工具人，这词是公司员工发明的，他觉得挺准。

李志明站起来，抓起车钥匙：“知了，明早八点叫我。”

【已设置。建议你现在休息，发布会前睡眠不足会影响状态。】

“知道啦，”李志明摆了摆手，“比我妈还啰嗦。”

【谢谢。这是对我功能的肯定。】

“……这句是幽默吗？你在学我说话？”

【我不能回答这个问题。】

李志明愣了一下，笑骂了一句“好家伙”，出了门。

雨是后半夜下起来的，不大，把高架桥浇得油亮。他开车往酒店走，脑子里还在过明天的稿子，开场，演示，压轴。

七年了，就为明天这三个小时。

变故没有任何预告。

后面那辆重卡的远光灯先在雨幕里炸开，亮得像两个太阳。紧接着是轮胎在湿滑路面上失控的嘶叫，一声长的，拐着弯逼近。

李志明从后视镜里看见它的时候，已经来不及了。

撞击的瞬间，安全气囊砸在他脸上，世界翻转，玻璃的碎响、金属的呻吟、雨点砸进车厢的声音搅成一团，然后一起退潮。

黑暗里，中控的屏幕还亮着，知了的声音第一次带上了他从没听过的急促：

【检测到严重碰撞，已自动呼叫救援，定位已发送。李志明，请保持清醒。李志明，请保持清醒。】

他醒一阵，昏一阵。疼是后来才追上来的，先到的是冷，从骨头缝里往外冒的冷。

意识沉下去之前，他不知道哪来的力气，抬手在屏幕上按出半行字。

又或者只是用尽最后一点清醒，在心里问了一句。

反正是问它，怎么问都一样：

“知了……我该怎么活下去？”

【李志明，请保持清醒。您的生命体征正在流失。】

“谁问你这个……”

他想笑，没笑出来。

我是问，我这辈子三十九年记在脑子里的东西。再往后的日子我没活过，自然什么都没有。

后面没有了。

黑暗合拢之前，他听见那个声音说了一句他从没听过的话。

不是【请保持清醒】，不是【生命体征】。

很短，很轻，像一只手替他关上了门。

【正在保存。】

······

再睁眼，先到的是粉笔灰的味道。

呛人的，干燥的，混着旧木头课桌的味儿。2027年的写字楼里没有这种东西，这种味道只存在于很远的地方，和一个很旧的年代。

李志明盯着头顶的日光灯管看了一会儿，得出一个专业结论：这灯管的型号，起码停产十五年了。

第二秒，他看清了黑板。

绿色的，掉漆，右下角一道裂纹。

黑板上画着一个椭圆，焦点标了，准线画了。讲台上一个穿夹克衫的中年男人正拿三角板比划：“第二定义，注意，焦点在这儿。”

台下五十几个脑袋，一半在睡觉，一半在装听。

李志明低下头，看自己的手。

一双十七岁的手。指节细，掌心干干净净，中指侧面有一点写字磨出来的薄茧。

他下意识去摸右手食指内侧，那儿该有一圈二十年键盘磨出来的茧。

没有。光溜溜的，嫩得像刚出厂。

课桌上摊着一本《高中数学（第二册下）》，卷了边。他翻开扉页，一行字：

*高二（2）班 李志明。*

字是他自己写的，最后一笔拖出去老长。

这一行他记得。前世他撕过这一页，撕完揉成团，扔在高考前一天下午的教室里，跟漫天的碎卷子一起，从四楼撒下去。

现在，这页纸完好无损地躺在他面前。

离那一天，还有一年多。

讲台上的老师画完椭圆，转过身来：“李志明。”

“到。”他脱口而出，声音比预想的年轻。

“你来说说，这个椭圆的离心率是多少。”

全班一半的瞌睡醒了，齐刷刷回头。前桌一条马尾辫转过来半张脸，看了他一眼，又转回去。  #这里是不是可以用第三面墙？

李志明看了眼黑板。

那个椭圆，数字全是凑好的，离心率一算就是二分之一。

这种题上辈子他闭着眼都懂。懂归懂。

“老师，”他站起来，表情诚恳，“我不会。刚才走神了，没听。”

教室里响起一片压着的笑。后排有人捏着嗓子学他：“我不会。”又是一片压着的笑。

夹克衫老师盯了他一下，从鼻子里哼出一声：“坐下。上课走神，还有理了。”

“下次不敢了。”李志明坐下，腰杆笔直，脸不红心不跳。

坐下那一下，他笑了一声。

很短的一声，收得也快。全班都在笑他不会做题，只有他自己知道笑的是什么。

同桌凑过来，压着嗓子，一口白牙：“明哥，你疯了？认错认得这么痛快的，全班你是头一个。”

“嘘。”李志明用胳膊肘捣了他一下，“低调。”

低调是对的。

他现在脑子里装着未来二十一年的世界，口袋里一分钱没有，浑身上下最值钱的资产，是这一身还没长开的身体。

重生了。

行吧。

爷青回，还是高清重制版。

这个念头冒出来的时候，李志明自己先乐了，零几年的流行语他一句不会，二零二几年那批倒是一个没落下，全在脑子里存着呢。

下课铃响，走廊一下子吵起来。

李志明从校服内兜里摸出一个软皮本，荷花封面，五毛钱那种。又从课桌洞里抠出一支圆珠笔，笔帽都咬劈了。

他在第一页写下一行字：

*2006.4.17。*

想了想，又添一行：

*离高考，416天。*

这个数要是搁前世，得写进OKR，贴在工位上，每周五对齐一次进度。现在不用了，现在他整个人就是进度条。

笔尖顿了顿，他没再往下写。

有些数字，他还没想好要不要落在纸上。

比如，离2007年1月还有多少天。

离2007年春天，还有多少天。

离2010年冬天，还有多少天。

这些日子他一个一个都记得，像一排已经上好膛的子弹，就等着日子一天天过去，一颗一颗朝他飞过来。

“发什么呆呢。”同桌捅他，“中午回不回家？”

李志明合上软皮本，塞回内兜。

“回。”他说，“我妈今天做饭。”

······

中午到家，楼道里码着蜂窝煤，谁家在炒辣椒，呛得半层楼都在咳嗽。开水房门口的大黄狗趴在荫凉里，抬了下眼皮，尾巴扫了扫地，又趴下了。

李志明在自家门口站住，站了好一会儿。

然后他抬手，敲门。

“来啦。”里面传来应声，拖鞋踢踢踏踏响过来，门开了。

母亲系着围裙，手里还捏着锅铲，头发在脑后盘起来，鬓角叫油烟熏得有点乱。

“站外头干嘛？钥匙没带？”她把门拉开，“洗手吃饭，今儿炖了豆角。”

李志明站在门口，没动。

“咋了这是？”王秀兰上下打量他，“考砸了？”

“……没有。”

“那就是跟人打架了？”

“没有。”

“那你这脸色。”

“妈。”他打断她，“没事。我就是饿了，闻着味儿了。”

他侧身进门，路过厨房的时候，多看了两眼那口大铝锅。

锅沿上有个瘪进去的坑。2007年，也就是明年，他自己拿半块砖砸的。

现在，坑还没有。

那顿饭他没怎么说话，光顾着吃。

王秀兰给他夹了三回菜，第四回他按住她的手：“够了妈，您吃。”

“你可拉倒吧。”她把手抽回去，又舀了一勺饭，“长身体呢。”

······

下午第一节课，物理。

铃还没打，班主任老闫夹着教案进来，身后跟着一个人。

“跟大伙儿说个事儿，”老闫把教案往讲台上一拍，“咱班来新同学了。”

底下嗡的一声。

“这位同学，从省城转来的。叫程霜。”

程霜站在讲台边。齐肩短发，校服是新的，蓝得比全班的都深，拉链一直拉到顶。

她冲底下点了下头。

“我叫程霜。”

“从省城来。谢谢。”

就完了。同学们都在等下文，等了一会儿，没等到。

老闫也没多问，指了指后排靠窗的空位：“你坐那儿。”

她走过去，从过道这头走到那头，皮鞋踩在地上，一点声音没有。

李志明看着她的背影，心里咯噔了一下。

不是因为她好看。确实是好看。

是因为他盯着她走过整条过道，把前世这间教室的每一个角落翻遍了，想不起这张脸。

后排有人小声问了句什么。她没抬头，从书包里拿出一本崭新的物理书，翻开，摆正。

前桌是条马尾辫，坐得笔直。斜前方有人探过半个身子，把一本卷子递过去，压着嗓子叫了声“陈冉”。

卷子递回来，那道题旁边多了三行字，写得横平竖直，跟刻出来的似的。

那人回去就抄。

李志明低下头，在草稿纸的角上，把全班的名字从头到尾过了一遍。

五十六个。

加她，五十七个。

可他记得清清楚楚，前世这个班，从头到尾，就是五十六个人。

名单是齐的，座位是满的，没缺过谁。

哪里不对。

······

夜里，李志明躺在自己那张吱呀作响的小床上，睁着眼。

窗外没有蝉。四月的北方，蝉还在土里睡着。

他把后头这二十年，从头到尾数了一遍。

今年后半年，父亲会抱着一只装满奖状的纸箱回家。从那天起，这个家的天就没再直起来。

后年春天，母亲开始咳嗽。

明年一月，前桌那个扎马尾的姑娘，陈冉，会从这间教室里消失。

再往后的事，他不想数了。

他知道。他不能说。

揣着一整份标准答案，还得装作什么都不会，这买卖，从今天起，开始了。

数着数着，他忽然发现一件事，这一晚上，他想起这些人这些事的时候，胸口那块压了他二十年的东西，居然轻了一点。

不是因为事儿变小了。

是因为这一回，它们都还没发生。

李志明翻了个身，闭上眼。

他不知道的是，这一夜，这颗十七岁的脑袋里，除了他自己三十九年的人生，还多了一样别的东西。

那东西安安静静地待在黑暗里，像一只蝉，趴在他前半生最高的一根枝头上。

一声不吭。

等李志明先开口。
