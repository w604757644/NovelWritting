## 二、四条指令的落地

### 1. 陈冉：父母是小城高官（隐晦表达），李家不动

**李家（不变）**：父＝机械厂厂办文员（26 年工龄），母＝纺织厂档案员，城东机械厂家属院。2006 秋改制买断。

**陈冉家（升级，全程不写官职）**——只落"能被 16 岁孩子读出来的信号"：

| 隐晦信号 | 写法 |
|---|---|
| 住得"不一样" | 她家不在家属院，在"有门岗的那条街"上 |
| 她爸的接送 | 偶尔有辆黑色轿车停在校门口，**她从不让人停近**，总是提前一个路口下车 |
| 家里的电话 | 她家的电话号码是五位数（2006 年小城"局里"才有的号段） |
| 她妈的手 | 不粗糙，指甲修剪过，说话用词讲究（"麻烦你""劳驾"） |
| 学校的态度 | 家长会那天，班主任对她爸格外客气；调座位、转班，别人办不了的她家能办 |
| 她自己不提 | 同学问"你爸妈干啥的"，她只说"上班"——**她烦的不是穷，是被当成"谁谁的女儿"** |

**驱动力从"经济"换成"尊严"**（这是本次最关键的替换）：
- 旧：学费 340 交不起 / 差点辍学 / 招工表 / 摆摊卖袜子
- 新：**她要证明自己不是靠家里**——她偏要考师范、偏要回小城教书、偏要签那个一千八的工作
- 保留落点：98 章"我看着"、125 章"我知道"
- 改写落点：108 章"我签一千八是因为我要自己养这个家" → **"我签一千八，是因为这是我自个儿挣的"**

### 2. 女配（程霜）提前到前三章，省城富家女，成绩碾压

| 项 | 定案 |
|---|---|
| 身份 | 省城来的插班生（**借读**，风头过了就走） |
| 入场 | **第 2 章**进班，第 1 章末埋（靠窗那个空位 + 一句"下午有个省城转来的"） |
| 杀伤力 | 第一次周测，数学满分 / 全班第一 / **省城教材比小城快半学期** |
| 她的作用 | ① 学习线上给主角一个"够得着的对手" ② 悬疑线（"前世名单无她"）③ 她不是来抢男主的，她是来"赢"的 |
| 锚点 | `沉默`（她的沉默是话说了一半咽回去） |

**"成绩碾压"怎么用才不崩**：不能让她压主角一辈子。设计成——**她强在起跑线（省城师资），主角强在后半程（39 岁的认知＋外挂）**。第一次周测她碾压，第二次月考被追平，期末被反超。这样"碾压"是推力不是碾压读者的爽点。

### 3. 高中从高二下最后两个月开始

**重生点：2006 年 4 月 17 日**（高二下学期，期中考刚过）。

**两级驱动（这是新版高中段的发动机）**：
- 第一级（第 1—30 章）：**2006 年 6 月底分班考，年级前三十进高三重点班**
- 第二级（第 31—80 章）：**高三一整年 → 2007 年 6 月高考**

好处：开篇第 1 章就有倒计时（还剩两个月），有明确的"赢"的标准（名次），有可量化的进步曲线（排名往上爬）。**学习驱动天然自带爽点节拍**——这正是原版最缺的。

### 4. 重点放在"学习成绩提高的过程"

主角与陈冉的互动改成**学习驱动**：
- 他问陈冉题目（陈冉是班里"认真的那一个"，基础扎实但不会拔高）
- 他教陈冉方法（估算、控分、题型归类）——**教的过程就是他自己的复盘**
- 陈冉的进步曲线 = 他的教学成果 = 可量化的爽点
- 感情线从"一起受苦"改成"一起变好"
