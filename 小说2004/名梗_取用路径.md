## 二、三步取用法

### L0 · 每章检查情境并定点取梗（2026-10-18用户更新）

> 纳入七步流程第3步设计和第6步声口调整：每章检查情境，按情境检索候选，尽量自然采用一些网络梗；用户指定梗优先结合上下文评估。不是可直接跳过的检查，也不是硬性数量任务。不合适时不塞梗，记录取舍。
> `python3 tools/meme_pick.py --list` 看节号 → `python3 tools/meme_pick.py 1 2 --top 8` 抽节（自动滤已用）→ `--find` / `--adopt`。
> 历史去重记录仅供参考；旧统计已删除，不能证明现稿是否使用。实际重复须核正文，允许有意义的重复与变奏，不设全书两次上限。
> 下面的手工命令保留作备用。

**① 定情绪核** —— 先想清楚这一场戏的情绪是什么，不是"这里缺个梗"。

**② 只抽 H6 的对应那一节**（不是整本 H6）：

```bash
R=~/.workbuddy/skills/net-meme-injection/references
awk '/^## 1\. 想说但不能说/,/^## 2\./' "$R/H6_按情绪检索表.md" | head -45
```

H6 的 14 个情绪编号（改 `1\.` 就能换节）：
`1` 想说但不能说（★重生者专属）｜`2` 代价·宿命·换命守恒｜`3` 贫穷·算计｜`4` 时间流逝·物是人非｜
`5` 忍着·硬撑｜`6` 心疼·温柔｜`7` 孤独·一个人扛｜`8` 得意·小赢｜`9` 失手·翻车｜`10` 不服·硬气

**③ 查是否已用**（读小文件，约 1.3K 字符）：

```bash
grep -n "颗粒度" 名梗_已用一行流.txt
```

### L1 · 需要确认年代／出处时（≈100—300 token）

```bash
grep -rn "朴实无华" "$R"/*.md        # 只看匹配行，不加载全文
```

### L2 · 全书大改造

才整读，且**必须分片分次**（一次一个文件，读完全部要分 3—4 次）。

## 三、绝对禁止的三件事

1. **禁止 `Read` 整本 H7（33K）或 H1（21K）** —— 这两个是最大的两颗雷。
2. **禁止为了"看看有没有能用的梗"而整读任何 H 文件** —— 永远先从 H6 入口走。
3. **禁止把梗清单整段贴进上下文** —— 需要时用 grep 定点取，只带 5—10 条进上下文。

## 四、成本对照（实测）

| 做法 | 成本 | 判定 |
|---|---|---|
| 整读全部 references | ≈83k token | ✗ **会打断任务** |
| 整读 H6 一本 | ≈6.3k token | △ 可接受但偏重 |
| **grep 抽 H6 的某一节** | **≈0.4—0.8k token** | ✓ **推荐** |
| grep 定点取词取证 | ≈0.1—0.3k token | ✓ 随时可用 |

> 上一条任务被反复打断的根因，就是做了第一行那种事。以后按第三行走。
